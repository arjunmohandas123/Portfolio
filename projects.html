01
Autonomous Robotic Vacuum Cleaner using SLAM & ROS
Mini Project · Mar – Jun 2023 · APJ Abdul Kalam Technological University
IEEE Published ICKECS 2024

Developed an autonomous mobile vacuum cleaning robot using ROS and SLAM on a Raspberry Pi 4B. The system integrates LiDAR-based environmental mapping, wheel encoder feedback, and autonomous navigation to explore and clean indoor environments. The project was published at IEEE ICKECS 2024.

  • Implemented GMapping SLAM using RPLIDAR A1 to generate 2D maps of indoor environments
  • Integrated wheel encoder odometry with LiDAR data for robot localization and navigation
  • Developed ROS-based navigation and obstacle avoidance functionality for autonomous movement
  • Integrated Raspberry Pi 4B, motor drivers, sensors, and differential-drive hardware
  • Tested the complete system in simulation and a physical environment

02
AI-Enabled Medical Humanoid Robot
B.Tech Final Year Project · Aug 2023 – May 2024
Final Year Project Multilingual Voice Interaction

Developed an AI-enabled medical assistance humanoid robot integrating embedded hardware, voice recognition, and natural language processing to facilitate interactive communication in healthcare-oriented applications. Implemented a dual-controller architecture using Raspberry Pi and Arduino, combining voice-based interaction with hardware-level control and sensor integration.

  • Designed a dual-controller architecture using Raspberry Pi and Arduino Uno for high-level processing and hardware interfacing
  • Integrated ReSpeaker microphone hardware for voice input and speech-based interaction
  • Developed an NLP pipeline using Python and Scikit-learn to process user queries and generate appropriate responses
  • Integrated Google Text-to-Speech (gTTS) for spoken responses in five languages
  • Implemented communication between the processing unit and embedded controller for coordinated system operation
  • Demonstrated the integrated prototype at a university project exhibition

03
Collaborative Robot for Automated Quality Inspection
Industry-Funded Project · Dimension Mechanics Pvt. Ltd. · 2023
Industry Collaboration Kerala Government Machinery Expo

Contributed to the development of an industry-funded collaborative robotic system for automated bottle-cap quality inspection and defective-product rejection. Focused on electrical system design, motor selection, wiring, actuator interfacing, and hardware-software integration to support the robot's inspection and pick-and-place workflow. The system was demonstrated at a machinery exhibition organised by the Kerala Government.

  • Selected suitable motors and electrical components based on system requirements
  • Designed and implemented electrical wiring and hardware connections for the robotic system
  • Integrated motors, actuators, and control electronics for coordinated robot operation
  • Contributed to control logic and hardware-software integration for automated pick-and-place operation
  • Participated in system testing, troubleshooting, and preparation for public exhibition
  • Presented the developed system at the Kerala Government Machinery Expo
